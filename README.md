SHARK TANK
==========
Everything is in this folder; nothing is installed and nothing is downloaded.
Unzip anywhere (any folder, any drive, spaces in the path are fine), then:
```
  Windows : double-click  "Launch Shark Tank.bat"  
  macOS   : double-click  "Launch Shark Tank.command"  
            (first time: right-click > Open; if it will not run, in Terminal: chmod +x "Launch Shark Tank.command")  
  Linux   : run  ./launch_shark_tank.sh   (chmod +x first if needed)
```
The launchers open the tank in its own resizable window using Chrome, Edge or Brave.
No launcher needed: you can also just open shark_tank.html in any modern browser
(Chrome, Edge, Firefox, Safari). Click once in the window to enable sound if the
browser blocks autoplay audio.

Controls: Feed menu (chum / fish food), New shark, Weather, Time (dawn/noon/dusk/night), Sound, Fullscreen, ? for the key list.
Keys: A = shark attack, B = boat, S = sound, F = feed, W = weather, T = time of day, N = new shark.
Needs a computer with graphics acceleration (WebGL). Settings are not saved; nothing leaves your machine.
